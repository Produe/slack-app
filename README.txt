Included tools
==============
After installation there are three additional tools added to the game folder:
"language-changer.exe" - for changing the game language
"dlc-toggler.exe" - for disabling/enabling DLCs without uninstalling
"dlc-uninstaller.exe" - for uninstalling DLCs
